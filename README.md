# دكّان — نموذج أولي للأندرويد

نموذج أولي لتطبيق بقالين حي الرشيدية في الموصل، مبني باستخدام Expo وReact Native.

## ما الذي يعمل في هذه النسخة؟
- تصفح محلات تجريبية والبحث عن اسم محل أو منتج.
- عرض أسعار المنتجات وساعات العمل وحالة التوفر.
- إضافة منتجات إلى السلة وحساب المجموع.
- اختيار التوصيل أو الاستلام من المحل.
- إدخال بيانات طلب تجريبي وطريقة الدفع النقدي عند الاستلام.
- نموذج تسجيل محل بانتظار موافقة المدير.
- إضافة منتج إلى محل في بيانات النسخة التجريبية.
- موافقة المدير، تعطيل المحل وإعادة تفعيله، والحذف بعد التأكيد.
- لوحة إدارة لتحديد تاريخ الإطلاق الرسمي واحتساب الشهر المجاني من هذا التاريخ.
- تسجيل الاشتراك يدويًا بعد استلام 1,000 دينار نقدًا أو التأكد من وصول تحويل زين كاش.
- حفظ سجل الدفعات وطريقة الدفع وتاريخ التجديد/الانتهاء ضمن بيانات النموذج المحلي.

## تشغيل المشروع
1. ثبّت Node.js على الكمبيوتر.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ: `npm install`
4. نفّذ: `npx expo start`
5. ثبّت تطبيق Expo Go على هاتف أندرويد وامسح رمز QR من الكمبيوتر.

## مهم قبل الإطلاق الحقيقي
هذه نسخة واجهات/نموذج أولي: البيانات محلية داخل التطبيق وليست مشتركة بين أجهزة البقالين والزبائن. الطلبات لا تُرسل فعلياً إلى المحلات، ولا يوجد تسجيل دخول آمن أو دفع آلي أو إشعارات حقيقية. تسجيل الاشتراكات والمدفوعات في هذه النسخة محلي داخل التطبيق التجريبي فقط، ولا يُشارك بين الأجهزة أو يُحفظ بشكل دائم عند إغلاق التطبيق. يلزم إضافة backend وقاعدة بيانات وقواعد صلاحيات (مثلاً Firebase أو Supabase)، وربط حسابات الزبائن والبقالين والمدير، وتخزين الطلبات وتحديثات المنتجات، ثم بناء APK واختباره قبل النشر.

## القرارات المعتمدة
- الاسم: دكّان.
- المنصة: Android.
- منطقة البداية: حي الرشيدية، الموصل، العراق.
- البقال يسجل محله وتتم الموافقة عليه قبل ظهوره.
- الزبون يختار التوصيل أو الاستلام.
- الدفع نقداً عند الاستلام في البداية؛ الدفع الإلكتروني لاحقاً.
- المدير يستطيع تعطيل المحل مؤقتاً أو حذفه نهائياً بعد تأكيد.
- أول شهر من تاريخ الإطلاق الرسمي مجاني لجميع المحلات.
- بعده 1,000 دينار عراقي لكل محل شهريًا.
- الدفع نقدًا أو عبر زين كاش، والمدير يسجّل الدفع يدويًا من لوحة الإدارة ويجدّد الاشتراك.
- انتهاء الاشتراك يوقف ظهور المحل مؤقتًا إلى أن يتم التجديد.
